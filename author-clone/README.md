# 作者思维分身(方案 B:长上下文 + 思维画像 + Prompt Caching)

不训练模型,不微调权重。把一位作者的**思维框架画像**和**全部原文**塞进
Claude 的长上下文并缓存,把模型指令成"以这个人的方式思考",用来对话和写
同等深度的原创文章。当天就能跑起来看效果。

---

## 一次性准备(约 5 分钟)

### 1. 装依赖
```bash
cd author-clone
python -m venv .venv && source .venv/bin/activate   # 可选,但推荐
pip install -r requirements.txt
```

### 2. 填 API key
```bash
cp .env.example .env
# 编辑 .env,把 ANTHROPIC_API_KEY 换成你在 https://platform.claude.com 申请的真实 key
```

### 3. 丢文章
把你的 30 篇文章放进 `articles/`,**一篇一个文件**,`.txt` 或 `.md` 都行。
文件名会被当作标题,起得有意义一点更好(如 `论政商关系的边界.md`)。

> 文章来自抖音截图?见下面的【步骤 0.5:截图 OCR】,自动转成 `articles/` 里的文本。

---

## 步骤 0.5(可选):抖音截图 → 文本

如果语料是你从抖音博主那截的图(图文帖 / 视频里的大段文字):

1. 你自己在抖音里截图(脚本不碰你的账号,也不爬抖音)。
2. 把图放进 `screenshots/`:
   - **一篇 = 一个子文件夹**:`screenshots/某博主-某篇/01.png 02.png ...`(多张拼成一篇)
   - 或 **一张图 = 一篇**:直接把单张图放在 `screenshots/` 根目录
3. 运行:
   ```bash
   python ocr_to_articles.py
   ```
   它会按顺序 OCR,把每篇写进 `articles/<名字>.txt`。完事抽查几篇有没有串行/漏字。

> 提示:抖音**图文帖**很多可以直接长按复制文字,比 OCR 更省更准——能复制就优先复制。

---

## 步骤 1:提炼作者的思维内核
```bash
python extract_profile.py
```
它会读完 `articles/` 里的全部文章,生成 `profile/thinking_profile.md`——
一份"如何像这个人一样思考"的操作手册(世界观 / 论证招式 / 心智模型 /
认知风格)。

> **强烈建议**:生成后打开 `profile/thinking_profile.md` 通读一遍,把不准的
> 删掉、把你更懂的补上。这份画像的"锋利度"直接决定分身的上限——
> 吃精料才能吐精料。

## 步骤 2:用起来
```bash
python chat.py
```
- 直接打字 = 跟分身对话
- `/write <题目>` = 让它就该题目写一篇完整原创文章
- `/reset` = 清空当前对话(画像和原文仍在)
- `/quit` = 退出

每条回复后会打印 token 用量,你能直观看到 **缓存命中** 后输入成本的大幅下降。

---

## 成本与模型
- 用的是 `claude-opus-4-8`(中文文采 + 推理最强档之一)。
- Prompt caching:第一次请求写一次缓存(约 1.25 倍),之后命中缓存的部分
  约 **0.1 倍** 输入价。30 篇语料缓存后,单次对话/写作通常只要**几毛钱**。
- 想更省可在两个脚本里把 `MODEL` 改成 `claude-sonnet-4-6`(更便宜,质量略降)。

## 调优方向(按效果排序)
1. **打磨画像**:步骤 1 生成后人工精修,是性价比最高的提升。
2. **精选语料**:宁可 20 篇真正锋利、同方向的,也别掺平庸的稀释掉风格。
3. **语料越多越像**:能找到该作者更多作品就一起丢进 `articles/`。
4. 若到此仍觉得"不够狠、还往平庸塌",再考虑升级到方案 A(真·微调,
   需换到可微调的模型如 GPT-4o-mini / Qwen / DeepSeek)。
